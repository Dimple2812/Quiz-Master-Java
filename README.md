# Quiz Master – Java AWT Quiz Application

## Project Overview
Quiz Master is a desktop-based quiz application developed using Java AWT. It provides an interactive environment for answering Java programming questions, tracking progress, and viewing quiz results.

## Objectives
- Develop a graphical user interface using Java AWT.
- Demonstrate event handling and layout management.
- Test knowledge of Java programming concepts.
- Calculate scores and display quiz performance.

## Features
- Interactive multiple-choice questions.
- Questions covering Java basics, OOP, and exceptions.
- Start, Previous, Next, and Submit controls.
- Quiz timer and score calculation.
- Answer review with explanations.
- Menu options and dialog boxes.

## Technologies Used
- **Programming Language:** Java
- **GUI Framework:** Abstract Window Toolkit (AWT)
- **Event Handling:** ActionListener and WindowAdapter
- **Layout Management:** Java AWT layout managers
- **Development Environment:** Visual Studio Code

## Java Concepts Demonstrated
- Frames, panels, labels, buttons, and text fields
- Choice, Checkbox, CheckboxGroup, and List components
- Event-driven programming
- Dialog boxes and menus
- Layout managers and window events

## How to Run the Project

### Prerequisites
Install the Java Development Kit (JDK) and ensure `java` and `javac` are available in your terminal.

### Steps
1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Compile the source file:

   ```bash
   javac QuizMaster.java
   ```

4. Run the application:

   ```bash
   java QuizMaster
   ```
